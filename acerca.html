Objetivo

Este sitio es un proyecto integrador para practicar HTML semántico y CSS mantenible. Cada sesión añade una capa sin reescribir lo anterior.

Principio guía

HTML describe qué es el contenido. CSS define cómo se ve. Si la estructura es sólida, el estilo y el comportamiento serán más fáciles de implementar.
